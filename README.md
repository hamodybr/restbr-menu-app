# RESTBR Simple V1

نسخة RESTBR البسيطة: منيو ثابت سريع لكل مطعم بدون Supabase وبدون تسجيل دخول وبدون Multi-tenant.

## ما الذي تعدله لكل مطعم؟

فقط ملفان رئيسيان:

1. `data/restaurant.json` — اسم المطعم، الهاتف، واتساب، اللغات، الألوان، الخلفية.
2. `data/menu.json` — الأقسام، الأصناف، الأسعار، الخيارات.

ضع الصور داخل `assets/products/`، والشعار في `assets/logo.png`، والخلفية في `assets/background.jpg`.

## المميزات

- عربي / كوردي / English.
- نفس تصميم الهاتف على الكمبيوتر والتابلت داخل Canvas بعرض 440px.
- بحث وأقسام.
- خيارات وأسعار.
- سلة منفصلة لكل مطعم.
- طلب WhatsApp.
- مشاركة الصنف.
- QR Code مع مشاركة/حفظ على iPhone.
- خلفية صورة أو فيديو.
- لا قاعدة بيانات ولا Auth ولا Service Worker ولا تعقيد كاش.

## إنشاء مطعم جديد

1. انسخ هذه الملفات إلى Repository جديد.
2. عدل `restaurant.json`.
3. عدل `menu.json`.
4. ارفع الصور.
5. فعّل GitHub Pages من `main / root`.
6. استخدم رابط GitHub Pages أو اربط دومين/ساب دومين لاحقًا.

GitHub نفسه يحتفظ بتاريخ كل تعديل، لذلك عندك Backup تلقائي عبر commit history.

## سياسة الصور المقترحة

- صور الأصناف: WebP/JPEG، هدف 200–500KB، حد عملي 2MB.
- الشعار: أقل من 1MB ويفضل WebP/PNG.
- فيديو الخلفية: 1080p، أقل من 12MB ويفضل أقل من 20 ثانية.

## الفلسفة

ابدأ بسيطًا. إذا أثبت RESTBR أن المطاعم تدفع وتحتاج لوحة Owner، نضيفها لاحقًا بناءً على طلب حقيقي، وليس قبل ذلك.
